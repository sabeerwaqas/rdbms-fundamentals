# Contributing

This repository is intentionally focused on the CS403 handout. Contributions should make a course topic easier to understand or practise, not expand the project without a clear learning benefit.

## Useful contributions

- Correct a technical mistake and provide a reliable reference.
- Improve a confusing explanation without changing the underlying concept.
- Add a small worked example, diagram, or original practice question.
- Provide a checked solution with reasoning.
- Improve an ER diagram by clarifying its assumptions and relationships.

## Before opening a pull request

1. Identify the relevant handout lecture and repository section.
2. Keep the change focused and place it in the matching section.
3. Use original wording. Do not copy pages, diagrams, or official assignment text from copyrighted course material.
4. For SQL, state the database engine, version, and dialect.
5. Verify code samples against the stated engine, or clearly mark them as pseudocode.
6. Explain non-obvious assumptions in examples and diagrams.

Small, verifiable improvements are preferred over large additions that are difficult to review.
