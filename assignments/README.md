# Assignments

This directory contains practice material and assignment guides related to the CS403 database-design topics.

- [Assignment 01 — Examination System Design](assignment-01-examination-system-design.md): original practice task created for this repository.
- [Assignment 02 — University Database ER Diagram](assignment-02-university-database-erd.md): study-oriented restatement of the Lab 3–Lab 4 assignment brief supplied by the repository owner.

For each assignment, read the scenario carefully, state assumptions, and make sure the submitted work follows the official course instructions. Assignment 02's supplied brief requires a Word document (.docx) containing the final ER diagram.

This repository does not host copies of the official course handout or assignment PDF. The Assignment 02 page preserves the key requirements in a concise restatement and adds modelling reminders to help with preparation.
