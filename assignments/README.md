## Learn before attempting Assignment 02

Start with [02 — Conceptual Database Design](../02-conceptual-database-design/README.md), especially:
1. Lecture 7 — entities and attributes.
2. Lecture 8 — keys.
3. Lecture 9 — relationships and relationship degree/cardinality.
4. Lecture 10 — minimum cardinality, roles, and dependencies.

The section also includes supertype/subtype concepts and the VU examination-system case study from Lectures 10–13.

**Lab/theory distinction:** Assignment 02 names Lab 3–Lab 4. The lecture links are related CS403 theory topics, not a conversion of lab numbers into lecture numbers.

This repository does not host copies of the official course handout or assignment document. Follow current LMS/instructor instructions if they differ from this guide.
