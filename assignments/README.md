# Assignments

This directory contains **original practice assignments** created for this repository. They are not copies of official university assignments.

Each assignment should state:

- The handout topics it practises.
- The scenario and assumptions.
- The tasks and expected deliverables.
- Any database-engine or notation requirement.
- A marking checklist or self-review criteria.
