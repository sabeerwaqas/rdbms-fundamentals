## Definition of done for a section

A section should contain only what is useful to learn and practise its assigned topics:

1. A concise explanation using the handout's terminology.
2. A small worked example, diagram, or SQL script where it improves understanding.
3. A few original practice questions.
4. A checked answer or explanation where appropriate.

## Content rules

- Do not add unrelated topics merely to increase the repository size.
- Do not duplicate the same explanation across multiple sections.
- Reuse the university examination-system scenario where it helps connect topics.
- Keep DBMS-independent concepts separate from vendor-specific implementation details.
- State the database engine and version for every executable SQL example.
- Do not publish the copyrighted course handout or copy official assignment text.
